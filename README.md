# Nai2API 酒馆助手生图脚本

SillyTavern 酒馆助手（JS-Slash-Runner / TavernHelper）用的全局脚本：根据聊天情节用 AI 生成生图提示词，调用 [nai.sta1n.cn](https://nai.sta1n.cn)（NovelAI 反向代理）出图，并把图片追加到聊天末尾。

**本仓库只存放成品脚本**，供直接引用；开发与版本历史在私有仓库中维护。

## 使用声明

这个脚本可以**任意转载、再分发、修改与使用**，不需要署名，也不需要征求同意。

它是个用 AI 辅助写出来的小脚本，作者不对可用性、稳定性或后果作任何担保；使用前请自行判断风险。脚本本身**不含任何密钥**——API Key 由你自己在酒馆的设置面板里填写，只保存在你的酒馆中。

## 安装

### 方式一：一行 import（推荐，可自动跟随更新）

前提：已安装酒馆助手扩展 `https://github.com/N0vi028/JS-Slash-Runner`（要求 SillyTavern ≥ 1.12.14）。

1. 酒馆助手扩展面板 → 脚本库 → 全局脚本 → 新建（命名随意，如 `NAI 生图`）
2. 脚本内容只填一行：

```js
import 'https://testingcf.jsdelivr.net/gh/ScrenSixerv/sillytavern-nai-draw-dist/nai_draw.js'
```

3. 在脚本编辑器的"脚本按钮"区域添加三个按钮，**名称必须完全一致**（含 emoji 与空格）：
   - `🎨NAI生图`
   - `💰NAI余额`
   - `⚙️NAI设置`
4. 启用脚本 → 点 `⚙️NAI设置` → 填入你的 API Key → 保存

> 关于版本号：上面这个地址不带版本号，等同于 `@latest`，会自动指向最新的发布版本（写法与 MVU 变量管理器一致）。CDN 与浏览器都会缓存它（实测 CDN 边缘最长 12 小时、浏览器最长 7 天），所以新版本发布后不一定立刻生效。想立刻用某个版本，就在地址里加上版本号，例如 `...nai-draw-dist@v25.0.0/nai_draw.js`——固定版本的缓存是长期的且内容永不改变，加载也更快。

### 方式二：粘贴全文

不想依赖 CDN 的话，直接打开本仓库的 [`nai_draw.js`](./nai_draw.js)，复制全文粘贴到脚本编辑器，同样配置上面三个按钮即可。这样更新时需要手动重新粘贴。

## 功能概览

- 按聊天情节用 AI 生成英文 Danbooru 标签提示词（可切换为英文自然语言描述模式，适配 NAI 5）
- 预置正面提示词 / 对 AI 的额外需求 / 自定义负面提示词
- **提示词预设**：把上面三个提示词字段存为预设，可应用/重命名/删除（跟随酒馆账号多端同步）
- **附加提示词条目**：多条要求注入给"写生图 tag 的 AI"，可勾选、可排序、可选插在指令开头或末尾
- 6 种画风预设；模型可选 NAI 4.5（1 点起/张）或 NAI 5（8 点起/张）；尺寸 3 朝向 × 1K/2K/4K，费用自动计算
- 同一提示词并发生成 1-5 张，**单张失败不影响其他张**；提交前按当前价目做余额预检
- 每条 AI 回复后自动生图（可开关）
- 图片以系统消息插入聊天，不会被模型当作"自己的发言"续写
- 三个手动按钮：生图 / 查余额 / 设置面板

## 入口

装好之后有四条触发路径：

1. 脚本按钮 `🎨NAI生图` — 手动生图（读取最近若干条聊天记录 → AI 写提示词 → 出图）
2. 脚本按钮 `💰NAI余额` — 查询剩余额度
3. 脚本按钮 `⚙️NAI设置` — 打开设置面板（API Key、画风、模型、尺寸、提示词等）
4. 自动生图 — 开启后监听酒馆的 `MESSAGE_RECEIVED` 事件，每条 AI 回复后自动出图

## 说明

- 依赖：酒馆助手（JS-Slash-Runner）+ SillyTavern ≥ 1.12.14；出图服务为 [nai.sta1n.cn](https://nai.sta1n.cn)，需要自备该服务的 API Key
- 作者：glm5.2 / glm5.3 / deepseek-v4.1-flash
- **调试日志**：脚本顶部有 `const DEBUG = false;` 开关。日常保持 `false`（控制台只留一行加载提示）；排查问题时改成 `true`，会输出**完整不截断**的排查信息——发送给 AI 的完整 sysPrompt（含情节上下文）、AI 原始输出、发送给生图模型的完整 prompt 与 negative，以及批量结果、余额预检等过程日志
  - 注意：`DEBUG` 开启时单条日志可达上万字符，浏览器开发者工具会把这些字符串留在内存里，长时间挂机 + 自动生图会持续占用内存，排查完记得改回 `false`
  - 想改 `DEBUG` 需要用上面的**方式二**（直接粘贴脚本），import 方式无法改动脚本内容
- 生图服务由第三方提供，额度与可用性取决于该服务，与本脚本无关
